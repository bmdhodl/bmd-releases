# BMD releases

Build. Manage. Deploy.

This repository holds public Windows release assets and update metadata for
[BMD](https://bmdpat.com/bmd). Application source code is maintained separately.

No public installer is available yet. The release candidate is undergoing
installation, update, and delivery verification. Do not use source archive
buttons as an application download.

When available, installers and checksums will be attached to versioned releases.
